# 2026-10-13

## RAG 检索方案优化：问答全文检索 + 问题闸门（v1.1）

**背景/证据**：用探针对比「带筛选 vs 全文检索」，4 个用例中 3 个的正确答案块被筛选直接排除：
- 「什么是字头？」+`--unit 1-1` → 定义在前言·体系总纲，被排除
- 「存在者整体是什么意思？」+`--unit 2-1` → 定义在第 1 卷/1 实在论，被排除
- 「什么是大他者？」+`--philosopher 拉康` → 定义段元数据未标拉康，被排除
根因：概念的定义句与块级元数据标注不总在同一处。

**改动**：
1. 问答链路去掉 `filter_ids` 筛选，`hybrid_search` 整篇检索；返回结果删除 `filters` 字段。
   - `answer()` 签名简化为 `(store, lex, question, cfg)`；`cli`/`server` 同步去掉筛选参数。
   - `hybrid_search` 的 `filters` 参数保留，仅供浏览式入口使用。
2. 新增 `philo_rag/gate.py`：检索前置闸门。类别 social/meta/fragment/too_short/off_topic/no_anchor；
   放行判据 = 词典概念/理论家 或 数值单元编号 或 哲学域词 或 提问句式。
   非 strict 档不因「词典未收录」拦截（宁可放行，避免误杀哲学提问）。
   - `gate` 配置段：enabled / min_chars / strict / hint；CLI 支持 `ask --no-gate`。
   - 跳过时返回 `{skipped: true, backend: "gate", gate: {...}, citations: []}`，不触发检索。
3. 新增 `scripts/check_gate.py`：26 条正负用例巡检（同 check_speaker.py 风格）。
4. Web 前端去掉问答筛选下拉；分面/单元卡片改为转成自然语言问题直接提问；跳过态单独渲染。
5. 文档：README（新增 §十二 检索前置）、docs/架构设计.md（新增 §8.1，原 8.1–8.5 顺延为 8.2–8.6，
   §八.5 引用改 §八.6）、docs/使用说明.md、config.yaml 注释。

**验证**：eval 指标与基线完全一致 Hit@1=85.71% / Hit@3=100% / MRR=0.9286（闸门不改检索）；
check_gate 26/26 通过；CLI/`--no-gate`/Web TestClient（含跳过态、忽略多余筛选字段）均通过。

**注意**：本次改动不触碰索引，无需重建。
